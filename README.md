# BAQ LIGA CS2

Турнир CS2 на 5 команд: отборочная группа каждый с каждым (bo1), затем плей-офф с верхней и нижней сеткой (bo3, гранд-финал bo5). Счет в реальном времени, дневной и ночной режим.

- `index.html` - страница для зрителей: матч в эфире или ближайший матч с обратным отсчетом, сетка, расписание, составы, итоговые места
- `admin.html` - админка: счет раундов по картам, технические победы, время матчей, посев и жеребьевка, составы, настройки
- `config.js` - настройки Firebase (пока не заполнен, работает демо-режим в одном браузере)
- `database.rules.json` - правила доступа: читать могут все, писать только админ
- `bg.jpg` - фон страницы с CT и T, закреплен на всю страницу
- `poster-mobile.jpg` - вертикальный постер, первый экран на телефоне и раздел «Афиши»
- `poster-desktop.jpg` - горизонтальный постер для раздела «Афиши»
- `logos/` - логотипы СМИ для первого экрана (Хабар, Qazaqstan, Qazsport, Kazmedia, Qazcontent)
- `favicon.ico`, `favicon-48.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `manifest.webmanifest` - значки сайта
- `og.jpg` - картинка-превью при отправке ссылки в WhatsApp и Telegram

Файлы открываются и двойным щелчком, без сервера.

## Firebase (база и вход в админку)

1. https://console.firebase.google.com - создать проект `baq-liga-cs2` (Google Analytics можно отключить).
2. Build - Realtime Database - Create database. Регион `europe-west1`, режим locked.
3. Build - Authentication - Get started - Email/Password - Enable.
4. Authentication - Users - Add user: email и пароль админа. Скопировать User UID.
5. Realtime Database - Rules: вставить `database.rules.json`, заменить `ВСТАВЬТЕ_UID_АДМИНА` на UID, Publish.
6. Project settings - Your apps - Web (`</>`): зарегистрировать приложение, скопировать `firebaseConfig` в `config.js`.
7. Authentication - Settings - Authorized domains - Add domain: `ЛОГИН.github.io`.

## GitHub Pages

1. Создать публичный репозиторий `baq-liga-cs2`, загрузить все файлы.
2. Settings - Pages - Deploy from a branch - `main` / `(root)` - Save.
3. Сайт: `https://ЛОГИН.github.io/baq-liga-cs2/`, админка: `.../admin.html`.

## Как вести турнир

- Жеребьевка группы: в админке задайте время и нажмите «Запланировать», зрители увидят обратный отсчет. В нужный момент нажмите «Провести жеребьевку»: у всех сразу появятся пары и время фиксации. После первого счета в группе жеребьевка блокируется.
- Группа: 5 туров по 2 матча bo1, одна команда в туре отдыхает. Таблица считается сама: победы, личная встреча, разница раундов, выигранные раунды. Техническая победа идет со счетом 13:0.
- Места 1-2 группы проходят в финал верхней сетки, места 3-5 в нижнюю. Плей-офф заполняется автоматически, когда сыграны все 10 матчей группы.
- В матче выберите карту, ведите раунды кнопками + и -, по окончании карты отметьте «Сыграна». Неявка оформляется полем «Техническая победа».
- Пики и баны капитаны проводят на CyberShoke, в админке отметьте, чей это пик или десайдер.
- Взносы отмечаются в разделе «Команды и взносы», призы по местам задаются в «Настройках».

- Постеры первого экрана меняются в админке, раздел «Постеры»: файл сжимается и хранится в базе (раздел baq_media в правилах). Кнопка «Вернуть стандартный» показывает файлы poster-desktop.jpg и poster-mobile.jpg.
